# Formatting task

Normalise the Markdown section below for a GitHub-flavoured academic paper:

- Keep the first line exactly as given (the `### Iteration ...` heading).
- Use `**Configuration.**`, `**Hypothesis and rationale.**`, `**Results.**`, `**Assessment.**`
  as bold run-in paragraph labels, each starting a new paragraph.
- Put hyperparameter or coordinate listings in a compact bullet list or a small table.
- Wrap identifiers and code in backticks; one blank line between blocks; no trailing spaces.
- Do not add or remove information. Every number in the input must appear unchanged in the output.

Return `formatted_markdown` with the formatted section.
