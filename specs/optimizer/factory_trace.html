0. How to read this

Indentation = "called by". Order on the page = order in time. LLM = an AI agent is called here (the only places AI is involved). SUBPROCESS = a separate Python process is spawned. THREADS = work fans out to parallel threads. writes / reads = files touched. Everything else is plain Python in the main thread — which is most of it, by design.

5. AgentRunner.run() — every LLM call, anywhere, goes through this

AgentRunner.run(call, router_log) agents.py:91 — prompt → route → guard → call → validate → (in-step retry). This is the only place the factory talks to an AI.
├─ render(user_template, payload) agents.py:54 reads prompts/<agent>.system.md + <agent>.user.md from disk
├─ schema = schemas.BY_NAME[(agent, purpose)] — the JSON contract for this call
└─ step-retry loop (STEP_RETRIES+1 tries, in place):
   ├─ router.route(ctx) router.py:113 — which model + effort? (R1 baseline, R3 quality, R4 complexity, R6 escalation, R2 step-retry effort bump, R5 fable-only-format)
   ├─ guard.check(...) isolation.py:37 — scan the outgoing prompt for canaries / foreign experiments. Leak → MacroFail, run over.
   ├─ writes prompts/<agent>_<purpose>_aN_rM.md — the exact routed prompt, on disk, auditable
   ├─ llm.call(decision, system, prompt, schema) LLM llm_client.py — the actual API call (claude CLI)
   ├─ writes prompts/….response.json (raw response + cost) · usage_cb → state["llm_usage"]
   ├─ extract_json() agents.py:62 → scrub_foreign() isolation.py:88 — parse the JSON; replace any foreign experiment mentions with "a prior experiment"
   ├─ jsonschema.validate(out, schema) → then the stage's own validator (the ones you saw in phases A and B)
   ├─ rejected → router_log.record("failed"), on_failure(), append the rejection to the prompt, retry with effort bumped (R2)
   └─ accepted → router_log.record("ok"), return the JSON. All step-retries exhausted → raise the error to the stage's retry machine (page 3)
Two retry levels, don't confuse them: the step-retry (inside AgentRunner) fixes one malformed answer in place, same attempt. The attempt loop (in member_core/phase_meta) is the 3-strikes machine that escalates agents up the ladder and eventually poisons. Step-retry is a rephrasing; attempts are new chances.
